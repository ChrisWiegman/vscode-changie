## 0.2.0 - 2026-05-10

### Security Fixes

* Reject .changie.yaml configs where changesDir, unreleasedDir, or changelogPath resolve outside the workspace root, preventing path traversal attacks via malicious repository configs
* Declare changie.executablePath as a restricted configuration so workspace-level overrides are ignored in untrusted workspaces, preventing arbitrary binary execution from malicious repos
* Validate version strings and use a function replacement in updatePackageVersionFiles to prevent JSON injection via special replacement patterns or quote characters in custom version input
* Add path confinement check in the deleteEntry command to ensure the target file resolves within the workspace root before deletion

### Features

* Automatically update version in package.json and package-lock.json when batching a release, controlled by the new changie.updateVersionFiles setting

### Bug Fixes

* Batch for Release now also runs changie merge to update CHANGELOG.md
